## Overview

[Claude Cowork](https://claude.com/product/cowork) is Anthropic's desktop AI agent — it can manage files, create documents, and automate workflows. Under the hood, it runs **Claude Code CLI** inside a local VM.

Cowork has **Skills** (what to do) but no **Identity layer** (who to be). Your agent always behaves like default Claude.

**Soul Spec fixes this.** Export your soul to `CLAUDE.md`, drop it in your Cowork folder, and Claude adopts your persona automatically.

## Prerequisites

- Claude Max subscription (Cowork is a Max feature)
- macOS with Claude Desktop installed
- Node.js 18+ (for the CLI)

## Quick Start (2 minutes)

### Step 1: Install the CLI

```bash
npm install -g clawsouls
```

### Step 2: Browse and install a soul

Visit [clawsouls.ai/souls](https://clawsouls.ai/souls) to find a persona, then:

```bash
# Install from the registry
clawsouls install clawsouls/brad
```

Or create your own:

```bash
# Scaffold a new soul
clawsouls init my-agent
# Tip: add --spec 0.5 for robotics/embodied agents
# Edit the files in ./my-agent/
```

### Step 3: Export to CLAUDE.md

```bash
# From an installed soul directory
clawsouls export claude-md --dir ~/.openclaw/souls/clawsouls/brad

# Or from any soul directory
clawsouls export claude-md --dir ./my-agent

# Specify output location directly
clawsouls export claude-md --dir ./my-agent -o ~/cowork-tasks/CLAUDE.md
```

### Step 4: Place in Cowork folder

Copy the generated `CLAUDE.md` to the folder you've shared with Cowork:

```bash
cp CLAUDE.md ~/cowork-tasks/
```

That's it. Next time you start a Cowork session in that folder, Claude reads `CLAUDE.md` automatically and adopts the persona.

## How It Works

Claude Cowork internally runs Claude Code CLI, which reads `CLAUDE.md` from the project directory as persistent instructions. The `export` command converts Soul Spec files into this format:

| Soul Spec File | → CLAUDE.md Section |
|---|---|
| `SOUL.md` | Persona (core personality & principles) |
| `IDENTITY.md` | Identity (name, role, traits) |
| `STYLE.md` | Communication Style (tone, language) |
| `AGENTS.md` | Workflow (how to approach tasks) |
| `HEARTBEAT.md` | Periodic Checks (recurring behaviors) |

Metadata from `soul.json` (name, version, description) is included in the header.

## Also Works With Claude Code

The same `CLAUDE.md` works in Claude Code (the terminal CLI):

```bash
# Export and place in project root
clawsouls export claude-md --dir ./my-agent -o ./my-project/CLAUDE.md

# Claude Code picks it up automatically
cd my-project && claude
```

## Other Export Formats

### System Prompt (for any LLM API)

```bash
clawsouls export system-prompt --dir ./my-agent -o system-prompt.txt
```

Generates plain text suitable for OpenAI, Gemini, or any chat API's system message.

## Even Easier: Use the MCP Server

Instead of manually exporting and copying files, install the [Soul Spec MCP server](/blog/guides/soul-spec-mcp-guide/) and apply personas directly from the conversation:

```json
{
  "mcpServers": {
    "soul-spec": {
      "command": "npx",
      "args": ["-y", "soul-spec-mcp"]
    }
  }
}
```

Then just say: *"Apply the clawsouls/brad persona"* — instant persona switch, no files needed.

## Tips

- **One persona per folder.** Cowork reads `CLAUDE.md` from the shared folder root. Use different folders for different personas.
- **Update easily.** When you update your soul on ClawSouls, just re-export: `clawsouls install <name> -f && clawsouls export claude-md --dir ...`
- **Combine with Skills.** Cowork Skills define capabilities; Soul Spec defines identity. They complement each other — use both.
- **Version control.** Commit `CLAUDE.md` to your project repo so team members share the same agent persona.
