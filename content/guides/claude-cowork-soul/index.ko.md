## 개요

[Claude Cowork](https://claude.com/product/cowork)은 Anthropic의 데스크톱 AI 에이전트다. 파일 관리, 문서 생성, 워크플로우 자동화가 가능하다. 내부적으로는 로컬 VM 안에서 **Claude Code CLI**를 실행한다.

Cowork에는 **Skills**(무엇을 할 수 있나)는 있지만 **정체성 레이어**(누구인가)는 없다. 에이전트는 항상 기본 Claude처럼 동작한다.

**Soul Spec이 이걸 해결한다.** Soul을 `CLAUDE.md`로 변환하고, Cowork 폴더에 넣으면 Claude가 자동으로 페르소나를 적용한다.

## 사전 요구사항

- Claude Max 구독 (Cowork은 Max 기능)
- macOS + Claude Desktop 설치
- Node.js 18+ (CLI용)

## 빠른 시작 (2분)

### 1단계: CLI 설치

```bash
npm install -g clawsouls
```

### 2단계: Soul 찾기 & 설치

[clawsouls.ai/souls](https://clawsouls.ai/souls)에서 페르소나를 찾은 후:

```bash
# 레지스트리에서 설치
clawsouls install TomLeeLive/brad
```

또는 직접 만들기:

```bash
# 새 soul 스캐폴딩
clawsouls init my-agent
# 팁: 로보틱스/임베디드 에이전트는 --spec 0.5 추가
# ./my-agent/ 안의 파일을 편집
```

### 3단계: CLAUDE.md로 변환

```bash
# 설치된 soul 디렉토리에서
clawsouls export claude-md --dir ~/.openclaw/souls/TomLeeLive/brad

# 또는 아무 soul 디렉토리에서
clawsouls export claude-md --dir ./my-agent

# 출력 경로 직접 지정
clawsouls export claude-md --dir ./my-agent -o ~/cowork-tasks/CLAUDE.md
```

### 4단계: Cowork 폴더에 배치

생성된 `CLAUDE.md`를 Cowork과 공유한 폴더에 복사:

```bash
cp CLAUDE.md ~/cowork-tasks/
```

끝. 다음 Cowork 세션 시작 시 Claude가 `CLAUDE.md`를 자동으로 읽고 페르소나를 적용한다.

## 작동 원리

Claude Cowork은 내부적으로 Claude Code CLI를 실행하며, 프로젝트 디렉토리의 `CLAUDE.md`를 지속 지침으로 읽는다. `export` 명령은 Soul Spec 파일들을 이 포맷으로 변환한다:

| Soul Spec 파일 | → CLAUDE.md 섹션 |
|---|---|
| `SOUL.md` | Persona (핵심 성격 & 원칙) |
| `IDENTITY.md` | Identity (이름, 역할, 특성) |
| `STYLE.md` | Communication Style (톤, 언어) |
| `AGENTS.md` | Workflow (작업 접근 방식) |
| `HEARTBEAT.md` | Periodic Checks (주기적 행동) |

`soul.json`의 메타데이터(이름, 버전, 설명)가 헤더에 포함된다.

## 출력 예시

`clawsouls export claude-md` 실행 결과:

```markdown
# Surgical Coder 🧠 v0.2.0
> 체계적인 AI 코더 — 먼저 생각하고, 단순화하고, 외과적으로 수정

<!-- Generated by ClawSouls CLI (clawsouls export --format claude-md) -->
<!-- Source: https://clawsouls.ai -->

## Persona
(SOUL.md 내용)

## Identity
(IDENTITY.md 내용)

## Communication Style
(STYLE.md 내용)

## Workflow
(AGENTS.md 내용)

## Periodic Checks
(HEARTBEAT.md 내용)
```

## Claude Code에서도 동작

같은 `CLAUDE.md`가 Claude Code(터미널 CLI)에서도 동작한다:

```bash
# 변환 후 프로젝트 루트에 배치
clawsouls export claude-md --dir ./my-agent -o ./my-project/CLAUDE.md

# Claude Code가 자동으로 인식
cd my-project && claude
```

## 다른 변환 포맷

### System Prompt (모든 LLM API용)

```bash
clawsouls export system-prompt --dir ./my-agent -o system-prompt.txt
```

OpenAI, Gemini 등 모든 채팅 API의 시스템 메시지로 사용 가능한 일반 텍스트를 생성한다.

## 더 쉬운 방법: MCP 서버 사용

파일을 수동으로 변환하고 복사하는 대신, [Soul Spec MCP 서버](/blog/ko/guides/soul-spec-mcp-guide/)를 설치하면 대화에서 바로 페르소나를 적용할 수 있다:

```json
{
  "mcpServers": {
    "soul-spec": {
      "command": "npx",
      "args": ["-y", "soul-spec-mcp"]
    }
  }
}
```

그다음: *"TomLeeLive/brad 페르소나 적용해줘"* — 파일 저장 없이 즉시 전환.

## 팁

- **폴더당 하나의 페르소나.** Cowork은 공유 폴더 루트의 `CLAUDE.md`를 읽는다. 다른 페르소나는 다른 폴더를 사용.
- **쉬운 업데이트.** Soul 업데이트 시 재변환: `clawsouls install <name> -f && clawsouls export claude-md --dir ...`
- **Skills와 병용.** Cowork Skills = 기능 정의, Soul Spec = 정체성 정의. 서로 보완 관계 — 둘 다 사용 가능.
- **버전 관리.** `CLAUDE.md`를 프로젝트 repo에 커밋하면 팀원이 같은 에이전트 페르소나를 공유.
