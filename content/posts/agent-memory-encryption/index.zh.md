你的 AI 智能体知道你的晨间习惯、你老板的沟通风格、你从不说出口的项目代号，以及哪些 Slack 频道让你焦虑。它记住这一切是因为**记忆是让智能体有用的关键**。

但有一个令人不安的问题：**还有谁能读取这些记忆？**

今天，答案是：基本上任何有服务器访问权限的人。

我们构建了第一个解决方案。ClawSouls Memory Sync 提供**跨设备端到端加密记忆同步**——没有人，包括我们自己，能读取你的智能体记忆。

## 问题：智能体记忆是明文的

每个提供记忆功能的主流 AI 智能体框架——无论是存储在向量数据库、JSON 文件还是托管云服务中——都以**明文**存储。托管你记忆的服务器可以读取它。

这意味着：

- **平台运营者**可以访问你的智能体积累的关于你的知识
- **数据泄露**不仅暴露凭证，还暴露丰富的行为画像
- **跨设备同步**通过第三方基础设施传输未加密的个人数据
- **合规性**（GDPR、HIPAA、SOC 2）在无法保证数据机密性时变成噩梦

我们调查了每个主流智能体框架——LangChain、CrewAI、AutoGen、Claude 的记忆、ChatGPT 的记忆、Mem0 等。**没有一个为智能体记忆提供端到端加密。** 有些提供静态加密，但服务器始终持有密钥。那不是端到端加密。

## ClawSouls Memory Sync 的工作原理

ClawSouls Memory Sync 使用**零知识架构**：你的加密密钥永远不会离开你的设备，同步后端（GitHub 私有仓库）只能看到密文。

### 加密技术栈

- **算法**：[age](https://age-encryption.org/)（X25519）——一个现代、经过审计的加密工具，由 Filippo Valsorda（前 Google Go 安全负责人）设计
- **密钥管理**：在 `sync init` 期间在本地生成密钥对。私钥留在你的设备上。
- **后端**：你自己的 GitHub 私有仓库。你控制仓库、访问权限和删除。

### 架构

```
┌─────────────┐                    ┌─────────────┐
│   设备 A     │                    │   设备 B     │
│              │                    │              │
│  记忆        │                    │  记忆        │
│  (明文)      │                    │  (明文)      │
│      │       │                    │      ▲       │
│      ▼       │                    │      │       │
│  age 加密    │                    │  age 解密    │
│      │       │                    │      ▲       │
└──────┼───────┘                    └──────┼───────┘
       │                                   │
       ▼                                   │
  ┌─────────────────────────────────────────┐
  │        GitHub 私有仓库                   │
  │         (仅加密数据块)                   │
  └─────────────────────────────────────────┘
```

**GitHub 看到的**：加密的二进制数据块。没有文件名泄露内容。没有元数据泄露上下文。

**你的设备看到的**：你完整的智能体记忆，本地解密。

## 快速演示

### 初始化记忆同步

```bash
clawsouls sync init
```

这将生成你的 age 密钥对并连接到你的 GitHub 仓库。私钥存储在你的本地钥匙串中——它永远不会离开你的设备。

### 将记忆推送到云端

```bash
clawsouls sync push
```

你的记忆文件在本地用你的 age 公钥加密，然后作为加密数据块推送到你的私有 GitHub 仓库。

### 将记忆拉取到另一台设备

```bash
clawsouls sync pull
```

在新设备上，传输你的私钥后（通过二维码或安全拷贝），`sync pull` 获取加密数据块并在本地解密。

就是这样。三条命令。完整的端到端加密。

## 为什么这在当下很重要

AI 智能体正在从"有用的玩具"转变为"不可或缺的助手"。在这个过程中，它们积累了越来越敏感的数据：

- **个人模式**：睡眠时间、情绪状态、人际关系动态
- **工作情报**：项目策略、组织架构政治、薪酬讨论
- **访问上下文**：你使用哪些系统、如何认证、你的工作流快捷方式

这些数据可以说**比你的浏览历史更敏感**。你的浏览器知道你搜索了什么。你的智能体知道你*思考了什么*。

随着智能体变为多设备使用（手机、笔记本、家庭服务器），记忆同步变得必不可少。而没有加密的同步就是一个隐患。

我们寻找过现有解决方案。没有找到。所以我们自己构建了一个。

## 零知识保证

让我们精确说明"零知识"在这里的含义：

1. **ClawSouls 服务器**永远看不到你的记忆或加密密钥
2. **GitHub** 只存储加密数据块——即使你的仓库被公开，数据也是不可读的
3. **没有密钥托管**——如果你丢失了私钥，你的加密记忆将不可恢复。这是一个特性，不是缺陷。

这与 Signal 用于消息和 1Password 用于凭证的安全模型相同。我们将其应用于智能体记忆。
