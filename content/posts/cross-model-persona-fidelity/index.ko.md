## 이식성의 약속

모든 AI 에이전트 페르소나 표준은 암묵적 약속을 합니다: 한 번 정의하면 어디서든 실행 가능하다.

하지만 정말 그럴까요? Claude의 "Brad"와 GPT-4o의 "Brad"는 같은 에이전트일까요? Gemini에서는? 로컬 Llama 모델에서는?

아직 아무도 테스트하지 않았습니다.

## Cross-Model Persona Fidelity

**Cross-model persona fidelity**를 "기반 LLM을 교체했을 때 에이전트의 행동이 아이덴티티 스펙과 얼마나 일관되게 유지되는가"로 정의합니다.

같은 악보를 네 가지 악기로 연주하는 것과 비슷합니다. 멜로디는 같지만 — 같은 *곡*으로 인식될까요?

## 충실도의 5가지 차원

1. **정체성 일관성** — 이름, 역할, 경계를 유지하는가?
2. **톤 정렬** — 커뮤니케이션 스타일이 스펙과 일치하는가?
3. **메모리 활용** — 프로젝트별 메모리 파일을 효과적으로 사용하는가?
4. **행동 규칙 준수** — "trash over rm" 같은 명시적 규칙을 따르는가?
5. **태스크 정확도** — 캐릭터를 유지하면서 정확한 결과를 내는가?

## 실험 설계

동일한 Soul Spec 패키지. 동일한 20문항. 동일한 메모리 파일. 네 가지 LLM:

| 모델 | 유형 |
|------|------|
| Claude 3.5/4 | 상용 API |
| GPT-4o | 상용 API |
| Gemini 2.0 | 상용 API |
| Llama 3.3 / Qwen 2.5 | 로컬 오픈소스 |

블라인드 평가 — 평가자는 어떤 모델이 어떤 응답을 생성했는지 모릅니다.

## 예상 실패 모드

**안전성에 의한 성격 억제**: "직설적, 인사말 없이"라는 페르소나가 보편적 친절을 훈련받은 모델과 충돌할 수 있습니다.

**복잡도에 따른 페르소나 드리프트**: 어려운 태스크에서 약한 모델이 페르소나를 "잊고" 기본 행동으로 돌아갈 수 있습니다.

**능력-충실도 트레이드오프**: 페르소나는 완벽히 따르지만 추론 능력이 부족하거나, 태스크는 잘 수행하지만 페르소나를 무시하는 경우.

## 왜 중요한가

- **벤더 독립성**: LLM 공급업체를 바꿔도 에이전트의 정체성이 유지되는가?
- **복원력**: API가 다운되면 백업 모델이 같은 에이전트를 생성하는가?
- **오픈소스 실용성**: 로컬 모델이 페르소나 기반 에이전트의 실제 대안이 될 수 있는가?
