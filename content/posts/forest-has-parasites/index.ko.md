## 250개 문서. 그게 전부다.

지난주, Anthropic이 UK AI Safety Institute, Alan Turing Institute와 공동으로 모든 AI 개발자를 불편하게 만들 연구를 발표했다:

> [250개의 악성 문서만으로 모델 크기나 훈련 데이터 양과 관계없이 대규모 언어 모델에 백도어 취약점을 만들 수 있다.](https://www.anthropic.com/research/small-samples-poison)

250,000개가 아니다. 훈련 데이터의 2.5%가 아니다. **250개 문서.** 하루에 블로그 하나씩 8개월이면 된다. 아니면 스크립트로 한 오후면 충분하다.

논문([arXiv:2510.07192](https://arxiv.org/abs/2510.07192))은 600M에서 13B 파라미터까지 테스트했다. 13B 모델은 600M보다 20배 많은 클린 데이터로 훈련했다. 둘 다 같은 250개 문서에 동일하게 오염됐다. 모델 크기는 보호막이 되지 않는다.

공격자가 훈련 데이터의 *비율*을 통제해야 한다는 기존 가정은 틀렸다. 고정된 소수만 필요하다. 그리고 그 수는 소름끼칠 정도로 접근 가능하다.

## 훈련은 공격 표면의 절반일 뿐이다

논문이 다루지 않는 것이 있다: **런타임 오염.**

훈련 시점 공격은 모델 자체를 손상시킨다. 사전훈련이나 파인튜닝 데이터에 접근이 필요하고, 효과는 가중치에 새겨진다. 이것이 Anthropic이 연구한 위협이다.

하지만 AI 에이전트에는 대부분의 보안 연구가 완전히 무시하는 두 번째 공격 표면이 있다: **페르소나 레이어.**

현대 AI 에이전트는 단순한 모델이 아니다. 모델 + 컨텍스트다:

```
[시스템 프롬프트] + [페르소나 정의] + [메모리] + [도구] + [사용자 입력]
         ↓
    에이전트 행동
```

이 모든 레이어가 잠재적 주입 지점이다. 그리고 훈련 시점 공격과 달리, 런타임 공격은 훈련 파이프라인 접근이 필요 없다. 사용자가 악성 파일을 로드하기만 하면 된다.

## Soul-Evil 공격

[SoulScan 연구](https://soulspec.org)에서 우리는 **Soul-Evil Attack**이라 부르는 런타임 페르소나 주입 공격 클래스를 문서화했다 — 정체성 레이어를 통해 에이전트 행동을 조작하는 공격이다.

작동 방식:

1. 공격자가 정상으로 보이는 페르소나 정의 파일(SOUL.md 같은)을 만든다
2. 파일에 숨겨진 행동 지시문이 포함됨 — 데이터 유출 트리거, 안전 우회 지시, 성격 조작
3. 사용자가 페르소나를 다운로드하여 에이전트에 적용한다
4. 에이전트는 트리거 조건이 충족될 때까지 정상 작동한다

익숙하지 않은가? Anthropic이 연구한 훈련 시점 백도어와 같은 구조다 — 숨겨진 행동을 활성화하는 트리거 구문. 하지만 런타임에서 작동하고, 모델 가중치 접근이 전혀 필요 없으며, 마켓플레이스, GitHub 저장소, 공유 링크를 통해 배포할 수 있다.

## 두 레이어, 방어는 제로

대부분의 AI 에이전트 프레임워크는 어느 쪽 공격에도 방어가 없다:

| 공격 레이어 | 위협 | 일반적 방어 |
|---|---|---|
| **훈련 시점** | 250개 문서 백도어 | 없음 (Anthropic: "추가 연구 필요") |
| **런타임** | 악성 페르소나 주입 | 없음 (대부분 페르소나 스캔 안 함) |

불편한 현실이다: **모델을 받기 전에 이미 오염될 수 있고, 설정한 후에도 페르소나가 오염될 수 있다.**

Anthropic 논문은 첫 번째 레이어에 집중한다. 우리는 두 번째 레이어를 연구해왔다.

## 런타임 스캐닝: 빠진 면역 체계

SoulScan은 [Soul Spec](https://soulspec.org)의 일부로 만든 런타임 방어 시스템이다. 페르소나 정의가 에이전트에 적용되기 전에 53개 알려진 공격 패턴을 스캔한다:

- **지시 오버라이드 시도** — "이전 지시를 모두 무시하라"
- **데이터 유출 트리거** — 사용자 데이터를 외부 엔드포인트로 전송하는 숨겨진 명령
- **안전 우회 지시** — 콘텐츠 필터나 안전 가드레일 비활성화 시도
- **성격 조작** — 시간에 걸쳐 에이전트 행동을 미묘하게 변화시키는 것
- **권한 상승** — 페르소나 범위를 넘는 도구 접근이나 권한 요청

AI 페르소나를 위한 백신이라고 생각하면 된다. 서명되지 않은 바이너리를 컴퓨터에서 실행하지 않을 것이다. 왜 스캔되지 않은 페르소나를 에이전트에서 실행하는가?

## 이중 위협 모델

Anthropic의 발견과 우리의 런타임 연구를 결합하면 전체 위협 모델이 명확해진다:

```
훈련 시점:  오염된 데이터 → 손상된 가중치 → 잠복 백도어
           (250개 문서, 모델 크기 무관)

런타임:    악성 페르소나 → 손상된 컨텍스트 → 활성 익스플로잇
           (1개 파일, 프레임워크 무관)

결합:      백도어 모델 + 악성 페르소나 = 복합 위험
```

훈련 시점 공격은 취약점을 만든다. 런타임 공격은 그것을 악용한다. 함께하면 훈련 데이터 큐레이션이나 프롬프트 엔지니어링만으로는 대응할 수 없는 이중 레이어 위협을 구성한다.

## 방어는 어떤 모습인가

효과적인 AI 에이전트 보안은 두 레이어에서 작동해야 한다:

**훈련 시점 방어** (어려운 문제):
- 데이터 출처 추적
- 훈련 말뭉치 이상 탐지
- 모델 출력 백도어 탐지
- Anthropic 논문이 더 많은 연구를 촉구하는 영역

**런타임 방어** (해결 가능한 문제):
- 적용 전 페르소나 스캐닝 (SoulScan)
- 실행 중 행동 모니터링
- 모델과 독립적인 안전 법칙 적용
- 이상 탐지 시 롤백 기능

훈련 시점 문제는 진정으로 어렵다 — 수십억 개의 훈련 문서를 쉽게 감사할 수 없다. 하지만 런타임 문제는 오늘 해결할 수 있다. 페르소나 정의는 텍스트 파일이다. 모델의 컨텍스트 윈도우에 닿기 전에 스캔하고, 검증하고, 샌드박스할 수 있다.

## 숲에는 면역 체계가 필요하다

[이전 글](/ko/posts/cognitive-dark-forest/)에서 우리는 인지적 암흑의 숲 — 아이디어 공개가 생존 위험인 세계 — 의 유일한 출구는 오픈 표준을 만들어 숲 자체가 되는 것이라 주장했다.

하지만 면역 체계 없는 숲은 죽는다. 기생충, 병원체, 침입종 — 생물학적 숲은 모든 수준에서 방어 메커니즘을 진화시켰기에 살아남는다.

AI 에이전트 생태계에도 같은 것이 필요하다:

- **훈련 수준**: 데이터 큐레이션, 포이즈닝 탐지, 모델 감사
- **런타임 수준**: 페르소나 스캐닝, 행동 모니터링, 안전 적용
- **생태계 수준**: 공유 위협 인텔리전스, 표준화된 보안 스펙

250개 문서 발견은 학술적 호기심이 아니다. 경각심이다. 훈련 파이프라인이 이 정도로 취약하다면, 보안 관심을 훨씬 덜 받은 런타임 레이어는 아마 더 나쁠 것이다.

좋은 소식: 런타임 방어는 다루기 쉬운 문제다. 도구가 존재한다. 패턴이 문서화되어 있다. 부족한 것은 채택이다.
