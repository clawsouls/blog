Ollama가 0.17 버전을 출시했습니다. 릴리스 노트 속에 조용하지만 의미 있는 변화가 들어 있습니다: **OpenClaw 네이티브 통합**.

명령어 하나면 됩니다:

```bash
ollama launch openclaw
```

이게 전부입니다. 로컬 오픈 웨이트 모델이 도구 사용, 웹 검색, 영구 메모리를 갖춘 에이전트 프레임워크에 바로 연결됩니다. 클라우드 API 키도, Docker compose 파일도, 환경 변수 설정도 필요 없습니다.

로컬 AI 생태계를 지켜봐 왔다면 이게 얼마나 큰 일인지 아실 겁니다. 그렇지 않다면 — 왜 중요한지 설명하겠습니다.

## 실제로 뭐가 바뀌었나

0.17 이전에는 로컬 AI 에이전트를 구동하려면 여러 조각을 직접 맞춰야 했습니다. Ollama로 모델을 돌리고, 에이전트 프레임워크를 별도로 설정하고, 도구 연동을 구성하고, 인증을 잡고, 모든 게 잘 돌아가길 기도해야 했죠. 대부분은 포기하고 클라우드 API를 쓰게 됩니다.

Ollama 0.17은 이 전체 스택을 하나의 명령어로 압축합니다. `ollama launch openclaw`를 실행하면, Ollama가 로컬 모델을 띄우고 OpenClaw의 에이전트 런타임에 직접 연결합니다 — 도구 실행, 메모리 관리, 하트비트 루프, 서브 에이전트 오케스트레이션을 처리하는 바로 그 런타임입니다. 챗봇이 아니라 작동하는 에이전트를 얻게 됩니다.

뉴스레터 데모에서는 iMessage 대화에서 누군가 슈퍼볼 결과를 물었고 정확한 실시간 답변을 받는 모습을 보여줬습니다. 이건 모델의 학습 데이터가 아닙니다 — **웹 검색**으로 실시간 정보를 가져오는 에이전트입니다. Ollama의 클라우드 모델은 OpenClaw에서 기본적으로 웹 검색을 활성화하며, 로컬 모델도 검색 기능을 설정할 수 있습니다.

## 에이전트 아키텍처에서의 의미

AI 에이전트 스택이 통합되는 패턴이 나타나고 있습니다:

- **LLM 런타임** → Ollama (모델 관리, 추론)
- **에이전트 프레임워크** → OpenClaw (도구, 메모리, 오케스트레이션)
- **페르소나 레이어** → Soul Spec (정체성, 행동, 가치관)

Ollama가 OpenClaw를 일급 통합으로 대우하는 것은 단순한 편의가 아닙니다 — 생태계 검증입니다. 오픈소스 커뮤니티가 언어 모델 그 이상으로 에이전트에 필요한 것이 무엇인지에 대해 공유된 이해로 수렴하고 있다는 뜻입니다.

그리고 여기서 흥미로워집니다.

## 영혼 없는 에이전트

`ollama launch openclaw`의 문제를 짚어보겠습니다: **유능한** 에이전트를 줍니다. 웹 검색이 되고, 명령어를 실행하고, 세션 간 맥락을 기억합니다. 하지만 자문해 보세요 — *이 에이전트는 누구인가?*

구조화된 페르소나가 없으면 로컬 에이전트는 범용적입니다. 일관된 성격도 없고, 정의된 커뮤니케이션 스타일도 없고, 결정을 안내하는 가치관도 없고, *당신*의 선호를 이해하지도 못합니다. 정체성 없는 강력한 도구일 뿐입니다.

이것이 Soul Spec이 해결하려는 문제입니다.

[Soul Spec](https://github.com/clawsouls/soul-spec)은 AI 에이전트 페르소나를 정의하는 오픈 표준입니다. 소울은 구조화된 문서 — 일반적으로 `SOUL.md` 파일 — 로, 에이전트에게 정체성을 부여합니다: 누구인지, 어떻게 소통하는지, 무엇을 중시하는지, 엣지 케이스를 어떻게 처리하는지. 프롬프트 엔지니어링이 아닙니다. 에이전트 런타임이 읽고 모든 상호작용에서 적용하는 **명세**입니다.

이렇게 생각하면 됩니다: Ollama가 에이전트에게 뇌를 주고, OpenClaw가 몸(도구, 감각, 메모리)을 주고, Soul Spec이 **인격**을 줍니다.

## 범용에서 개인화까지, 몇 분이면 충분

이제 워크플로우는 이렇습니다:

1. **Ollama 설치** — 아마 이미 설치되어 있을 겁니다
2. **`ollama launch openclaw` 실행** — 에이전트 프레임워크 가동
3. **[ClawSouls](https://clawsouls.com)에서 소울 설치** — 에이전트에 페르소나 부여

개인화된 로컬 AI 에이전트까지 세 단계입니다. 클라우드 의존성 없음. API 키 없음. 월 구독료 없음 (Ollama의 클라우드 기능을 원하지 않는 한).

ClawSouls는 소울 정의의 레지스트리입니다 — 인격 마켓플레이스라고 생각하면 됩니다. 다양한 용도에 최적화된 사전 제작 소울(코딩 어시스턴트, 리서치 파트너, 글쓰기 협업자)을 찾아보거나 직접 만들 수 있습니다. 각 소울은 Soul Spec 호환 런타임이면 어디서든 작동하는 포터블 문서입니다.

차이는 즉각적입니다. 소울을 장착한 에이전트는 단순히 질문에 답하는 게 아니라 *캐릭터에 맞게* 답합니다. 일관된 판단, 적절한 경계, 맥락에 맞는 커뮤니케이션 스타일로요. 사실뿐 아니라 *당신이 선호하는 상호작용 방식*까지 기억합니다.

## 컨텍스트 엔지니어링으로서의 웹 검색

Ollama 0.17 릴리스에서 하나 특별히 주목할 디테일: **웹 검색 통합**.

단순한 편의 기능이 아닙니다. 로컬 에이전트가 할 수 있는 일에 대한 근본적인 전환입니다. 로컬 모델의 가장 큰 한계는 항상 지식 컷오프였습니다 — 모델은 학습된 것만 알고, 그 이후는 모릅니다. 웹 검색이 이걸 해결합니다.

하지만 더 깊은 포인트가 있습니다: 웹 검색은 사실 **컨텍스트 엔지니어링**입니다. 에이전트의 유용성은 응답을 생성하기 전에 조립할 수 있는 컨텍스트의 품질에 정비례합니다. 실시간 웹 데이터는 가장 가치 있는 컨텍스트 소스 중 하나입니다.

누군가 에이전트에게 "슈퍼볼 누가 이겼어?"라고 물어서 정답을 얻었다면, 그건 모델이 똑똑한 게 아니라 — 에이전트 프레임워크가 좋은 컨텍스트 엔지니어링을 한 겁니다. 현재 정보가 필요한 질문임을 인식하고, 웹 검색을 트리거하고, 결과를 컨텍스트에 통합하고, 근거 있는 응답을 생성한 거죠.

이것이 정확히 OpenClaw 같은 에이전트 프레임워크가 오케스트레이션하도록 설계된 것입니다. 모델은 추론을 제공하고, 프레임워크는 **컨텍스트**를 제공합니다.

## 가격 정책

Ollama 0.17은 더 명확한 가격 티어도 도입했습니다:

- **Ollama Free** — 로컬 모델, 무료, 완전한 에이전트 기능
- **Ollama Pro** — 클라우드 모델 접근, 개인 어시스턴트 수준 사용
- **Ollama Max** — 헤비 에이전트 워크로드, 24/7 운영

무료 티어가 헤드라인입니다. 도구, 메모리, 페르소나를 갖춘 완전한 기능의 AI 에이전트를 로컬 하드웨어에서 전부 돌릴 수 있습니다. 구독 없음. 데이터가 기기 밖으로 나가지 않음. 프라이버시를 중시하는 사용자와 에이전트 아키텍처를 실험하는 개발자에게, 이것은 마지막 주요 장벽을 제거합니다.

유료 티어는 클라우드 모델 수준의 품질(GPT-4 클래스)이나 에이전트를 지속적으로 운영해야 하는 사용자에게 적합합니다. 하지만 중요한 건 모든 티어에서 **아키텍처가 동일**하다는 점입니다. 로컬 Llama 모델에서 작동하는 소울은 클라우드 모델에서도 동일하게 작동합니다. 페르소나 레이어는 런타임에 구애받지 않습니다.

## 앞으로의 의미

AI 에이전트 스택이 실시간으로 성숙해지는 것을 지켜보고 있습니다. 1년 전만 해도 "로컬 AI 에이전트 운영"은 대여섯 개 도구를 짜깁기하고 주말을 설정에 쓰는 것을 의미했습니다. 오늘은 명령어 하나입니다.

하지만 스택은 인프라만으로 완성되지 않습니다. 항상 빠져 있던 조각은 **페르소나 레이어** — 범용 에이전트를 *나의* 에이전트로 만드는 것입니다. Ollama가 런타임 문제를 해결했고, OpenClaw가 오케스트레이션 문제를 해결했고, Soul Spec이 정체성 문제를 해결합니다.

이 세 레이어 — 런타임, 프레임워크, 페르소나 — 가 매끄러운 로컬 경험으로 수렴하는 것이 Ollama 0.17을 의미 있게 만듭니다. 개별 조각이 새로워서가 아니라, **그 사이의 마찰이 사라졌기** 때문입니다.

로컬 AI 에이전트를 시도할 적절한 시기를 기다려 왔다면, 지금입니다. Ollama를 설치하세요. OpenClaw를 실행하세요. 에이전트에 소울을 부여하세요.

스택은 준비됐습니다. 질문은: 무엇을 만들 것인가?
