## 문제: 에이전트가 모든 것을 기억하거나 아무것도 기억하지 않는다

모든 AI 에이전트 개발자가 같은 딜레마에 직면한다:

- **메모리 없음** → 에이전트가 세션 간에 모든 것을 잊는다. 모든 대화가 제로부터 시작한다.
- **완전한 메모리** → 에이전트가 모든 것을 완벽한 충실도로 기억한다. 사용자가 적대적이었던 그 한 번을 포함해서. 오래된 결정들을 포함해서. 어제의 중요한 업데이트를 묻어버리는 6개월 전의 노이즈를 포함해서.

둘 다 옳지 않다. 인간은 수백만 년 전에 이를 해결했다: **중요한 것은 기억하고 그렇지 않은 것은 잊는다.** 완벽하지는 않지만 — 새로운 경험에 적응하면서도 일관된 정체성을 유지할 수 있을 정도로.

AI 에이전트도 같은 것이 필요하다.

## Soul Memory 소개

**Soul Memory**는 AI 에이전트를 위한 4계층 적응형 메모리 아키텍처다. 정체성과 경험을 분리하고, 작업 메모리에 시간적 소멸을 적용하며, 중요한 메모리를 영구 저장소로 자동 승격시킨다.

```
┌─────────────────────────────────────────┐
│  T0: SOUL (정체성)                       │
│  "내가 누구인가" — 불변, 인간 소유        │
├─────────────────────────────────────────┤
│  T1: CORE MEMORY (상록수형)              │
│  "절대 잊지 말아야 할 것" — 소멸 없음     │
├─────────────────────────────────────────┤
│  T2: WORKING MEMORY (시간형)             │
│  "최근에 일어난 일" — 소멸함              │
├─────────────────────────────────────────┤
│  T3: SESSION MEMORY (일시형)             │
│  "지금 논의하고 있는 것" — 사라짐         │
└─────────────────────────────────────────┘
```

### T0: Soul (정체성)

에이전트의 `SOUL.md`와 `IDENTITY.md`. 이들은 *에이전트가 누구인지*를 정의한다 — 성격, 가치관, 행동 규칙. 매 세션마다 새롭게 로드되고, 에이전트에 의해 수정되지 않으며, 소멸되지 않는다.

이는 [메모리-정체성 패러독스](/posts/perfect-memory-breaks-ai-identity/)에 대한 에이전트의 방어책이다 — 아무리 많은 경험이 축적되어도 정체성 앵커는 변하지 않는다.

### T1: Core Memory (상록수형)

`MEMORY.md`와 날짜가 없는 주제 파일들 (`memory/roadmap.md`, `memory/trademark.md`). 이들은 엄선된 장기 지식을 저장한다: 결정, 아키텍처 선택, 핵심 관계, 전략.

**시간적 소멸 없음.** 핵심 메모리는 오늘 작성되었든 1년 전에 작성되었든 항상 완전한 관련성을 갖는다. 이는 에이전트의 "절대 잊지 않을 것" 저장소다.

### T2: Working Memory (시간형)

`memory/2026-03-19.md`처럼 날짜가 찍힌 파일들. 이들은 일일 작업 로그, 디버그 노트, 회의 기록, 작업 진행 상황이다.

**23일 반감기의 시간적 소멸.** 오늘의 작업 메모리는 완전한 관련성을 갖는다. 지난주는 81%. 지난달은 41%. 3개월 전? 7%. 6개월? 검색에서 사실상 보이지 않음 — 하지만 필요하면 디스크에 여전히 있다.

이것이 핵심 통찰이다: **에이전트의 일일 로그는 자연스럽게 사라져야 한다**, 지난 화요일에 무엇을 먹었는지에 대한 당신 자신의 기억처럼.

### T3: Session Memory (일시형)

현재 대화 컨텍스트. 세션이 끝나면 사라진다. 이는 표준 LLM 컨텍스트 윈도우다 — 지속성이 필요하지 않다.

## 마법: 시간적 소멸

소멸 함수는 간단하다:

```
final_score = semantic_score × exp(-0.0301 × age_in_days)
```

| 나이 | 가중치 | 에이전트의 행동 |
|------|--------|---------------|
| 오늘 | 100% | "방금 작업했어" |
| 1주 | 81% | "최근 컨텍스트야" |
| 23일 | 50% | "이거 기억해" |
| 1개월 | 41% | "익숙한 것 같은데" |
| 3개월 | 7% | "애매하게... 확인해볼게..." |

**아무것도 삭제되지 않는다.** 소멸은 검색 순위에만 영향을 준다. 오래된 것에 대해 명시적으로 묻는다면, 여전히 거기 있다 — 단지 의미적 점수가 높아야 나타날 뿐이다.

## 메모리 승격: T2 → T1

중요한 질문: 중요한 작업 메모리가 어떻게 영구적 핵심 메모리가 되는가?

세 가지 메커니즘:

### 1. 규칙 기반 탐지

에이전트가 다음을 포함하는 작업 메모리를 자동으로 플래그 처리:
- 결정과 약속
- 아키텍처/설계 변경
- 재정 조건 (가격, 비용, 마진)
- 법적 사안 (상표, 특허, 계약)
- 핵심 관계 (파트너, 고객)
- 전략과 로드맵 항목

### 2. 접근 빈도 승격

작업 메모리가 서로 다른 세션에서 3번 이상 검색되면, 명백히 중요하다. 승격을 위해 플래그 처리.

### 3. 주간 검토

매주 금요일, 에이전트가 한 주의 작업 메모리를 스캔하고, 승격 후보를 식별하고, 인간에게 묻는다: *"이것들이 영구적이 되어야 할까?"*

이는 인간이 잠 동안 기억을 통합하는 방식을 반영한다 — 신호와 노이즈를 분리하는 주기적 검토.

## 설정하기

Soul Memory는 [SoulClaw](https://github.com/clawsouls/soulclaw) (우리의 OpenClaw 포크)와 함께 작동한다. 최소 설정은 다음과 같다:

### 1. 시간적 소멸 활성화

`openclaw.json`에서:

```json
{
  "agents": {
    "defaults": {
      "memorySearch": {
        "query": {
          "hybrid": {
            "temporalDecay": {
              "enabled": true,
              "halfLifeDays": 23
            }
          }
        }
      }
    }
  }
}
```

### 2. 메모리 파일 정리

```
workspace/
├── SOUL.md              # T0: 절대 변하지 않음
├── IDENTITY.md          # T0: 절대 변하지 않음
├── MEMORY.md            # T1: 큐레이션된, 영구적
├── memory/
│   ├── roadmap.md       # T1: 상록수 (날짜 없음 = 소멸 없음)
│   ├── 2026-03-19.md    # T2: 일일 로그 (소멸함)
│   └── 2026-03-18.md    # T2: 일일 로그 (소멸함)
```

### 3. 임베딩 모델 업그레이드 (권장)

```bash
ollama pull bge-m3
# 그런 다음 config에서 provider: "ollama", model: "bge-m3" 설정
openclaw memory index --force
```

bge-m3은 100개 이상의 언어 지원과 훨씬 나은 의미적 검색 품질을 제공한다 (기본 모델의 ~60 대비 MTEB 63).

## 왜 RAG만 사용하지 않는가?

표준 RAG는 유사성으로 청크를 검색한다. 다음을 모른다:
- 지난주 결정이 지난달 것을 재정의한다는 것
- `SOUL.md`가 축적된 노이즈에 의해 압도되어서는 안 된다는 것
- 3개월 전의 적대적 상호작용 로그가 오늘의 행동에 영향을 주어서는 안 된다는 것
- 일부 메모리는 영구적이어야 하고 다른 것들은 사라져야 한다는 것

Soul Memory는 바닐라 RAG가 부족한 *시간적이고 정체성 차원*을 추가한다.

## 더 큰 그림

Soul Memory는 에이전트 정체성 스택의 한 조각이다:

1. **[Soul Spec](https://github.com/clawsouls/soul-spec)** — 에이전트가 누구인지 정의
2. **Soul Memory** — 중요한 것은 기억하고 그렇지 않은 것은 잊기
3. **[SoulScan](https://clawsouls.ai)** — 정체성 무결성 검증

함께, 이들은 장기 실행 AI 에이전트의 근본적 도전을 해결한다: **유용한 경험을 축적하면서도 수천 번의 상호작용에 걸쳐 일관된 정체성을 유지하는 것.**
